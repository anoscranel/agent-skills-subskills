# Alternatives and options

## Standard

A decision can only be as good as the best option it considers. The most common quiet failure is a thin option set: the analysis compares two familiar paths and the best answer was never on the table. Building the option set is therefore a deliberate step, not a preliminary. Every set includes the status quo, stated as a real option with its own costs and risks, because "do nothing" is a choice with consequences that are easy to leave unpriced.

The set is then tested for quality, not just length. Remove dominated options, those worse than another on every objective, since they cannot win and only add noise. Look for the missing kind: the reversible probe, the staged commitment, the option to wait for information, the hybrid. Watch for optionality that is valuable precisely because the future is uncertain; a small, cheap option that preserves the right to act later is often worth more than a large irreversible commitment made now. When the option set is thin, the fix is generation, which is the neighbouring ideation craft, not more analysis of the same two paths.

Primary sources: <https://en.wikipedia.org/wiki/Decision_analysis> and <https://en.wikipedia.org/wiki/Real_options_analysis>.

## Decision rules

- Always include the status quo as a priced option, not a default.
- Remove dominated options before valuing anything.
- Add the missing kinds: probe, staged, wait, hybrid, reversible.
- Price optionality: the right to act later has value under uncertainty.
- Treat a two-option set as a warning sign, not a finish line.
- If the set is thin, generate more before analysing further.

## Procedure

1. List the candidate options, including the status quo.
2. Eliminate any option dominated on every objective.
3. Ask which kinds are missing: probe, staged, wait, hybrid.
4. Note where an option preserves or destroys future choice.
5. Price the status quo's own costs and risks explicitly.
6. If the set is thin, run generation before returning to analysis.

## Anti-patterns

- Comparing two familiar options and calling it a decision.
- Treating "do nothing" as free or as no decision.
- Keeping dominated options to look thorough.
- Ignoring the value of waiting or of a reversible probe.
- Analysing harder instead of widening a thin option set.

## Done checklist

- [ ] Status quo included and priced.
- [ ] Dominated options removed.
- [ ] Missing kinds considered and added where relevant.
- [ ] Optionality noted and valued.
- [ ] Thin set widened before analysis.
- [ ] Final set is genuine, not decorative.
