# Uncertainty and probabilities

## Standard

A decision under uncertainty needs probabilities, and the honest ones are elicited, not asserted. Start from the base rate: how often does this kind of thing happen in the reference class of comparable situations? The inside view, the story of why this case is special, is where overconfidence breeds; the outside view, the base rate of similar endeavours, is the anchor that corrects it. Reference-class forecasting is the discipline of taking the outside view first and adjusting only for what is genuinely different about this case.

Probabilities should be stated as ranges or distributions, not point estimates, and the people supplying them should be calibrated. A calibrated forecaster's 70% predictions come true about 70% of the time, and calibration is a trainable, measurable skill rather than a personality trait. Where a single number is required for a computation, it is drawn from a stated range, and the sensitivity of the answer to that number is checked rather than assumed. False precision, a confident point estimate built on a guess, is the characteristic failure of this step.

Primary sources: <https://en.wikipedia.org/wiki/Base_rate> and <https://doi.org/10.1080/09654310701747936>.

## Decision rules

- Anchor on the base rate of the reference class before the inside story.
- State probabilities as ranges or distributions, not bare points.
- Elicit from calibrated people where possible; record who estimated.
- Adjust the base rate only for genuinely differentiating facts.
- Convert a range to a point only for computation, then test sensitivity.
- Refuse false precision: a guessed probability is a guess, however formatted.

## Procedure

1. Identify the uncertain quantities the decision depends on.
2. Choose a reference class and find its base rate for each.
3. Elicit probabilities as ranges from the best-calibrated sources.
4. Adjust for case-specific facts, stating each adjustment.
5. Record the estimators and their calibration evidence.
6. Flag which estimates most drive the decision for sensitivity testing.

## Anti-patterns

- Inside-view storytelling with no base-rate anchor.
- Confident point estimates presented as knowledge.
- Treating an uncalibrated expert's confidence as a probability.
- Adjusting the base rate for narrative rather than differentiating facts.
- Hiding the most load-bearing guess inside a single number.

## Done checklist

- [ ] Uncertain quantities identified.
- [ ] Base rates found for each.
- [ ] Probabilities stated as ranges.
- [ ] Estimators and calibration recorded.
- [ ] Adjustments justified by differentiating facts.
- [ ] Load-bearing estimates flagged for sensitivity.
