# Onboarding and adoption

## Standard

Onboarding is where retention is won or lost. A customer who reaches first value quickly is far more likely to stay; one who stalls in setup churns before they ever see the benefit. The onboarding goal is time-to-value: the shortest path from signature to the customer's first realised outcome, not a tour of every feature. Define first value explicitly per segment, then strip the path to it.

Adoption is the next stage: turning first value into habitual use embedded in the customer's workflow. Define adoption milestones as observable behaviours that correlate with retention — the activation events that, when a customer hits them, predict they stay. Onboarding is a designed sequence with an owner, a target time-to-value, and a milestone that marks when a customer has genuinely adopted, not merely signed up.

Primary sources: <https://en.wikipedia.org/wiki/Onboarding> and <https://en.wikipedia.org/wiki/Customer_success>.

Segment onboarding by customer complexity, not by a single template. A small team with a simple use case should reach value in days through self-serve; an enterprise with integrations and multiple stakeholders needs a guided, longer path. Forcing every customer through the same onboarding either overwhelms the small ones or under-serves the large ones, and both stall before value.

## Decision rules

- Define first value explicitly per segment; optimise time-to-value.
- Strip onboarding to the shortest path to first value, not a feature tour.
- Define adoption milestones as behaviours that correlate with retention.
- Assign an owner and a target duration to onboarding.
- Distinguish activation (first value) from adoption (habitual use).
- Track where customers stall and fix the stall, not the symptom.

## Procedure

1. Define first value and the target time-to-value per segment.
2. Map the shortest path from signature to first value.
3. Identify activation events that predict retention.
4. Sequence onboarding with an owner per step.
5. Define the adoption milestone that marks habitual use.
6. Instrument stalls and review them on a cadence.

## Anti-patterns

- Onboarding as a product tour with no outcome.
- No defined first value, so customers drift in setup.
- Measuring adoption as logins rather than workflow use.
- Onboarding with no owner and no target duration.
- Ignoring where customers stall before churning.

## Done checklist

- [ ] First value defined per segment.
- [ ] Time-to-value targeted and measured.
- [ ] Onboarding path stripped to the essential.
- [ ] Adoption milestones tied to retention.
- [ ] Owner and duration per onboarding step.
- [ ] Stalls instrumented and reviewed.
