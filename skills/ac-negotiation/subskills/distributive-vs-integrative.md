# Distributive versus integrative negotiation

## Standard

Every negotiation contains two kinds of work: claiming value and creating value. Distributive negotiation treats the pie as fixed and bargains over who gets the larger share; integrative negotiation looks for ways to enlarge the pie before dividing it. The mistake is to treat every negotiation as purely one or the other. Most real deals have both a fixed component and room to create value, and the integrative work usually comes first, because value created is value both sides can later claim.

The engine of integrative negotiation is difference. Parties value issues differently, and those differences allow trades that benefit both. If you care most about the delivery date and the counterparty cares most about price, a concession on the date can buy a concession on price, and both sides end up better off than a straight split. This is logrolling: conceding on what you value less to gain on what you value more. Finding it requires multiple issues on the table and honest information about each side's priorities, which is why single-issue positional bargaining so often leaves value unclaimed.

Primary sources: <https://en.wikipedia.org/wiki/Integrative_negotiation> and <https://en.wikipedia.org/wiki/Distributive_negotiation>.

## Decision rules

- Identify which parts of the deal are fixed-pie and which can be expanded before bargaining.
- Put several issues on the table; a single issue forces a distributive fight.
- Trade across issues by your differing priorities, not by splitting every issue down the middle.
- Share information about your priorities when it helps create value, not your reservation point.
- Create value first, then claim it; reversing the order usually shrinks the pie.
- Do not assume the other side's gain is your loss; test for compatible interests first.

## Procedure

1. List every issue in the deal, not just the headline one.
2. Rank the issues by importance to you and estimate their importance to the counterparty.
3. Identify trades where a low-priority concession buys a high-priority gain.
4. Propose package offers rather than single-issue concessions.
5. Resolve the value-creating moves before arguing over the fixed-pie remainder.
6. Record which trades created value so the final split reflects them.

## Anti-patterns

- Treating every negotiation as a fixed pie to be divided.
- Conceding on the issue you care most about to appear reasonable.
- Bargaining one issue at a time and losing the trades.
- Revealing your reservation point while exploring options.
- Splitting every issue evenly and calling it fair.

## Done checklist

- [ ] Fixed-pie and expandable parts identified.
- [ ] Multiple issues on the table.
- [ ] Issue priorities ranked for both sides.
- [ ] Trades across issues proposed as packages.
- [ ] Value created before value claimed.
- [ ] Reservation point withheld during option exploration.
