# Coding and analysis

## Standard

Qualitative analysis moves from raw data to an interpretive account through systematic coding. In the grounded-theory tradition, open coding fractures the data into concepts, axial coding relates them into categories, and selective coding integrates around a core category. In thematic analysis, following Braun and Clarke, the analyst familiarises with the data, generates initial codes, searches for themes, reviews them, defines and names them, and produces the account. The two are not interchangeable: grounded theory builds an explanatory theory; thematic analysis identifies patterned meaning. Choose deliberately and apply the chosen logic consistently.

Constant comparison is the engine: each new piece of data is compared with the codes and categories already formed, so the account is built from the data rather than imposed on it. Analytic memos record the researcher's developing interpretations, hunches, and decisions — they are where the analysis actually happens. Codes become themes only when they cohere around a central organising concept and are evidenced across the data, not when a phrase recurs often. Frequency is not significance.

Primary sources: <https://en.wikipedia.org/wiki/Thematic_analysis> and <https://doi.org/10.1191/1478088706qp063oa>.

## Decision rules

- Choose the analytic logic (grounded theory or thematic analysis) and apply it consistently.
- Code systematically from the data, not from a preconceived framework.
- Use constant comparison so the account is built from the data.
- Write analytic memos throughout; they carry the interpretation.
- Form themes around a central organising concept, evidenced across the data.
- Treat frequency of a code as no evidence of its significance.

## Procedure

1. Familiarise with the data; read and re-read with memos.
2. Generate initial codes systematically across the dataset.
3. Compare new data with existing codes and categories.
4. Collapse codes into candidate themes or categories.
5. Review themes against the coded extracts and the whole dataset.
6. Define, name, and evidence each theme; write the account.

## Anti-patterns

- Coding from a fixed framework imposed before reading the data.
- Treating a recurring word or phrase as a theme.
- No memos, so the interpretive reasoning is lost.
- Mixing grounded-theory and thematic-analysis logic inconsistently.
- Themes that do not cohere or that are evidenced in only one extract.

## Done checklist

- [ ] Analytic logic chosen and applied consistently.
- [ ] Codes generated from the data.
- [ ] Constant comparison used throughout.
- [ ] Analytic memos written.
- [ ] Themes cohere and are evidenced across the data.
- [ ] Frequency not mistaken for significance.
